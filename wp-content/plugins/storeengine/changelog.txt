== Changelog ==

= 2.2.0 - 26/07/2026 =

Added:
- Product Quick View — open any catalog product in a modal straight from the shop/archive, with configurable trigger position and animation, an optional whole-card trigger, full keyboard/accessibility support, and working variant price and add-to-cart.
- Wishlist (core) — a heart control on product cards and single-product pages lets shoppers save products; the card heart reveals on hover.
- Product Compare — select multiple products and compare their details side by side.
- Recently Viewed products — surface the products a shopper has recently browsed.
- Size Chart library — reusable size guides assigned by brand or category and shown as a size guide on the product page.
- Reviews & FAQ — a buyer review form with photo/video review media and a dashboard entry, an admin Reviews management page (with REST), plus per-product and global FAQ libraries.
- Custom product gallery — carousel, stacked and grid layouts with lightbox and zoom, product-editor gallery swatches, and a unified image/video gallery.
- Shop-card variant switcher — Shopify-style variant swatches on archive/shop cards to switch the pictured and priced variant without opening the product.
- Sticky add-to-cart bar and cart-drawer auto-open — a persistent add-to-cart bar (mobile and desktop) and an option to open the cart drawer automatically after adding.
- Embeddable product shortcode — drop a single product anywhere via shortcode.
- Couriers — the shipment/courier framework now ships in free core (previously Pro): a Shipments model, provider registry, auto-push on paid orders, and order-status sync back to the order. Concrete carriers ship in the free StoreEngine Connectors companion plugin.
- Courier OAuth authentication — a reusable OAuth2 engine supporting one-click "Connect" (3-legged authorization code with automatic token refresh) and server-to-server client-credentials, with Connect/Disconnect from Settings → Couriers.
- Dropshipping addon — auto-route paid orders to suppliers for direct fulfilment, create/email purchase orders, capture supplier tracking, and roll fulfilment status back onto the order.
- Suppliers & Purchase Orders addon — track suppliers and raise POs, with a magic-link supplier portal, PO approvals, and low-stock auto-reorder.
- Companion-plugin ecosystem — the License SDK is now loaded by core so the free StoreEngine Payments / Connectors plugins receive automatic updates even without Pro; install-only teasers on the Payment method and Couriers settings surface them with one-click install & activate.
- Incoming webhooks receiver.
- Single-product analytics.
- Scheduled backups.
- Shortcode → block bridge — StoreEngine shortcodes are available as native blocks.
- First-run setup wizard redesign — product-type-aware capability selection, a Payments step, and a post-setup "connect your payment method" notice.
- A Refund action in the order editor top bar; Copy Link in the product price menu (generates a checkout link without a reload); and a Tools-page tab API so addons can contribute their own tabs.
- A "Couriers" tab on the Add-ons screen linking to courier settings.

Improved:
- Migrated admin selects to the shared Tailwind Select component, resolving country/state selection and various select sizing/width/hover issues.
- Affiliate & commission workflow, including always-on self-referral protection with an optional "Allow Self-Referral" toggle.
- Major admin UI refresh onto a shared Tailwind design kit — Settings, the Products editor, the Setup wizard, and standard pages rebuilt on one system (themed checkboxes/switches/selects, consistent cards, borders and spacing, redesigned notice cards with a grouping bell).
- Admin navigation reorganized — collapsible parent groups in the sidebar, raw-route child menus, Fraud Shield promoted to a top-level menu, and centralized submenu ordering.
- Dashboard — a shared page header across core and vendor pages, and affiliate referral + balance merged into one card.
- Checkout, cart and instant-checkout polish — card backgrounds, refined order-bump cards, and installment "Future Payments" summaries.
- Add-ons — payment-gateway and courier cards moved off the main list; the "requires add-ons" notice is a clean footer chip and long descriptions are clamped so cards align evenly.

Fixed:
- Product-gallery video embeds hardened (defense-in-depth), plus assorted product-layout, scroll and storefront UI fixes.
- Coupons on subscription orders (and the coupon code now appears in the email); optional compare-at price no longer blocks re-saving; tax invoice issues; funnel issues; missing shortcode pages.
- Courier settings toggles rendered with a stuck switch thumb; buttons default to type="button" to prevent accidental form submits; and a broad admin UI/spacing/border audit across tables, modals, notices and list-table footers.

Changed:
- Couriers use the shared addon schema-version system; removed unused table-drop code (StoreEngine never drops tables) and a bundled frontend font.

= 2.1.1 - 13/07/2026 =

Added:
- Multi-vendor: admin-initiated custom vendor payouts. An "Add Payout" modal lets an admin pay a vendor any amount up to their available balance, independent of a withdrawal request, so a large earned balance can be settled in instalments. New admin-only routes `POST /withdrawals/pay` (records a `paid` withdrawal and debits the balance) and `GET /withdrawals/vendor-balance`, both capped at the available balance with a re-check guard against concurrent overdraw.
- Affiliate registration form: additional fields (first/last name, website URL, promotional methods, terms agreement) and a Registration section in the Affiliate settings.

Improved:
- Affiliate addon: reworked affiliates admin table and settings, plus numerous correctness fixes across registration and payouts.

Fixed:
- Stripe Elements failing to load on checkout. The card iframe's real `ready`/`loaderror` events are now tracked so the confirm/submit path waits for the iframe to finish mounting instead of throwing "Element … the ready event has been" errors; and the checkout page now sends `no-store` (like the cart) so Chromium back/forward-cache no longer restores a stale page where Stripe never re-initialises.
- Instant Checkout: Stripe/payment initialisation and related issues in the embedded checkout app.
- Coupons: applying a coupon while the cart is still initialising no longer triggers a site-wide fatal — a missing/invalid cart is handled gracefully (logged, treated as "coupon not applied").
- Payments: building the order snapshot during checkout no longer fatals on a null date or price object; the build is wrapped so failures return a clear error instead of a "Cannot read properties of null" crash.
- Membership: resolved reported membership issues.
- Admin screens: JavaScript strings are now translatable. The admin bundle's strings were missing from the translation template because the build output could not be parsed during POT generation; POT extraction now transpiles the built scripts first so every admin string is included.
- Setup wizard: strings are now shown translated. Registered script translations for the setup wizard script (`storeengine-setup-scripts`) so its JavaScript strings load the correct locale.

= 2.1.0 - 09/07/2026 =

Added:
- New Funnel Builder addon — build sales/checkout funnels with dedicated step pages, an aBlocks-powered canvas, a status toggle in the funnels table, performance cards, and a Tools-section shortcode.
- New email/content builder editor (replaces the Quill editor) for product descriptions and email bodies, with raw HTML source editing, inline image size/alignment controls, and full H1–H6 heading support.
- Stripe Automatic Tax integration (Stripe addon). Opt-in via Settings → Tax → Enable Stripe Tax; delegates per-line tax calculation to Stripe's Tax Calculations API and records transactions / reversals via Tax Transactions for filing-ready reports. Adds settings keys `enable_stripe_tax`, `stripe_tax_default_code`, `stripe_tax_shipping_code`, `stripe_tax_fallback_to_local` (stored inside the main `storeengine_settings` blob). New post meta `_stripe_tax_code`, user meta `_stripe_tax_status`, `_stripe_tax_id_type`, `_stripe_tax_id_value`, order meta `_stripe_tax_calculation_id`, `_stripe_tax_transaction_id`, and refund meta `_stripe_tax_reversal_id`. New REST route `GET /storeengine/v1/stripe-tax/status`. New core filter `storeengine/tax/calculator` for third-party tax engines.
- Instant Checkout: unified contact + OTP verification block, phone country-code selector with an Email/Phone toggle, and verified-state persistence across page reloads.
- AI product-description and taxonomy-term generation with an inline "AI generate" button.
- POS: new cart-page UI, product pagination + search, and quick add-product patterns.
- Invoice preview, account-move, tax/footer notices, and skeleton loaders.

Improved:
- Admin UI refresh across the Pages table, Logs (items-per-page), modals, cards, access-group creation, and the add-customer/guest and add-product screens.
- Currency switcher copy; checkout & analytics UI; low-stock and parked-product handling.

Fixed:
- REST API requests on sites using Plain permalinks.
- Subscriptions: cart-page rendering, COD/bank-transfer and Buy-Now hidden for subscription products, renewal handling, and reactivation before payment.
- Catalog display bugs; duplicate robots meta tag; add-to-cart quantity increment on single-product pages.
- Instant-checkout guest-prefill and verified-cookie edge cases.
- Admin coupon restore; AI description not updating the editor; affiliate-creation validation.
- Stock processing and order-completion sync.

Security & Compatibility:
- Security (Multi-Vendor): Fixed a privilege-escalation chain — a self-registered pending vendor could approve their own vendor account (REST and wp-admin), mark their own withdrawal payout as paid, and change the global commission rate. Vendor-management, payout-status and settings-write actions now require an administrator (`manage_options`), with an explicit self-approval guard.
- Security (Downloads): Fixed a path-traversal in the digital-download handler — a crafted downloadable file URL (`../` or absolute path) could read files outside the store. Downloads are now restricted to allowed roots (WP install / wp-content / uploads / secure-uploads, filterable), and `../` segments are rejected when saving downloadable files.
- Full WordPress Plugin Check remediation — the distributed build now reports 0 errors. Output escaping (esc_html/esc_attr/esc_url/wp_kses_post), all dynamic SQL parameterised via `$wpdb->prepare()` (identifiers via `%i`), direct-file-access guards, and complete i18n (translator comments, single-literal strings, text domains).
- Logger now writes via WP_Filesystem; EU-VAT validation uses `wp_remote_post()` instead of cURL. Added an `is_uploaded_file()` guard to the backup-restore upload.
- WordPress 6.5–7.0 compatibility (`get_userdata()`, guarded 6.8/6.9 APIs). Tested up to 7.0.

Developer / QA notes:
- log-cleanup now computes its retention threshold in UTC to match the logger's UTC timestamps — verify old-log purging on sites in non-UTC timezones.
- Cart/Checkout/Thank-you/Dashboard page templates are now rendered via `Fs::render_template()` (include + output buffering) — verify these pages are created with correct block content on a fresh install and on upgrade/migration.
- Backup export/download/restore intentionally keep direct filesystem I/O (justified `phpcs:ignore`) because WP_Filesystem cannot stream/append — smoke-test a full export → download → restore cycle.
